# Roadmap

1. Ship a container image with the three environments (core, DLC, KPMS) pinned.
2. Add ONNX/TorchScript export for CPU-only deployment.
3. Provide a weight-release script with checksum verification.
4. Extend the class set with defecation/jumping once labelled data exist.
5. Add a pose-free mode (video model + SGATF with pseudo-syllables) for labs
   without DeepLabCut.
6. Continuous integration: add a GPU smoke test on a self-hosted runner.
